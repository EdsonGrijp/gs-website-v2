# GS Website v2.0

> Site institucional desenvolvido para apresentar a identidade, os serviços e as soluções da Grijp Systems.

## 📖 Sobre o projeto

O GS Website v2.0 é a segunda versão do site institucional da Grijp Systems.

O projeto está sendo desenvolvido do zero, seguindo boas práticas de desenvolvimento front-end, organização de código e arquitetura de componentes. O objetivo é criar uma interface moderna, responsiva e escalável, refletindo a identidade da empresa e proporcionando uma experiência agradável ao usuário.

---

## 🎯 Objetivos

- Desenvolver uma interface moderna e intuitiva.
- Aplicar boas práticas de HTML, CSS e JavaScript.
- Criar um código organizado e reutilizável.
- Garantir responsividade para diferentes dispositivos.
- Evoluir continuamente o projeto através de novas versões.
